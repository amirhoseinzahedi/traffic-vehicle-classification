# Traffic Vehicle Classification

Reliable traffic-vehicle classification using CNNs and transfer learning.

## Project Goal

Build a reproducible image-classification system for cropped
traffic-camera vehicle images.

The project focuses not only on accuracy, but also on:

- data quality
- leakage prevention
- reproducibility
- controlled experiments
- class imbalance
- transfer learning
- error analysis
- uncertainty and human review
